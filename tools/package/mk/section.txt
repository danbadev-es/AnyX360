MORTAL KOMBAT KOMPLETE EDITION (in testing)
==========================================================
Your copy: the Games on Demand package (in an archive or a folder) or a folder with the disc's
files. The downloadable content next to it (the fighters, the costumes, the Kombat Pass) is
installed too. Local versus for two players; the tag modes for up to four.
Saved games and settings: %LOCALAPPDATA%\AnyX360\MortalKombat

CONTROLS
Player 1: keyboard and mouse, standing in for a controller; player 2: the first controller. A
controller for each player is recommended: open F2 > Players and set each player's device.

  Left stick / D-pad                    W A S D / Arrows
  A / B / X / Y                         Space / V / E / F
  LB / RB                               Q / R
  LT / RT                               Right / left mouse button
  Start / Back                          Esc / Tab

What each button does is in the game's Options, as on the console.

VERSUS (TWO PLAYERS)
In the main menu, RB switches "1 JUGADOR" (1 player) to "2 JUGADORES" (2 players): Versus mode,
one against one or two against two. At the character select the second player presses START on
their controller to join. After a match, the loser's controller chooses the rematch, a new
fighter or the main menu.
